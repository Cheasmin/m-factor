# RC M-Factor Calculator - ASCE 41-17

Interactive presentation calculator for ASCE/SEI 41-17 linear-procedure m-factors for reinforced-concrete beams, columns, and beam-column joints. The RC beam workflow automatically derives expected flexural strength from rectangular-section geometry, reinforcement, and expected material properties.

Open the [public calculator](https://cheasmin.github.io/m-factor/starter.html) or use `starter.html` locally.

> Engineering notice: This tool is edition-locked to ASCE/SEI 41-17. Automatic beam strength is limited to the stated rectangular-section scope and assumes developed reinforcement. Verify component classification, knowledge factor, analysis demands, material data, development, governing edition, and all project requirements before final approval. Nonlinear procedures require the applicable modeling and deformation criteria; the m-factor is not a strength multiplier.
