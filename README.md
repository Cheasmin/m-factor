# RC M-Factor Calculator - ASCE 41-17

Interactive presentation calculator for ASCE/SEI 41-17 linear-procedure m-factors for reinforced-concrete beams, columns, and beam-column joints. The RC beam and column workflows accept actual section and reinforcing-steel inputs and automatically derive expected flexural strength. The column workflow also derives the Table 10-10 axial ratio, transverse-reinforcement ratio, flexural-yield shear, and Eq. (10-3) column shear strength.

Open the [public calculator](https://cheasmin.github.io/m-factor/starter.html) or use `starter.html` locally.

> Engineering notice: This tool is edition-locked to ASCE/SEI 41-17. Automatic strength is limited to the stated beam/column section-analysis scopes and assumes developed reinforcement. Column axial loads, moment-to-shear ratio, clear height/end-yield model, and analysis demand remain project inputs. Verify component classification, knowledge factor, analysis demands, material data, development, governing edition, and all project requirements before final approval. Nonlinear procedures require the applicable modeling and deformation criteria; the m-factor is not a strength multiplier.
