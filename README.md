# RC M-Factor Calculator - ASCE 41-17

Interactive presentation calculator for ASCE/SEI 41-17 linear-procedure m-factors for reinforced-concrete beams, columns, and beam-column joints.

Open `starter.html` through the published GitHub Pages link.

> Engineering notice: This tool is edition-locked to ASCE/SEI 41-17. Verify component classification, knowledge factor, demand, expected strength, governing edition, and all project requirements before final approval. Nonlinear procedures require the applicable modeling and deformation criteria; the m-factor is not a strength multiplier.
