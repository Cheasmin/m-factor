Existing RC moment frames

Select and interpolate the ASCE 41 m-factor

For linear static or linear dynamic evaluation of reinforced-concrete beam-column moment frames. The engine implements ASCE/SEI 41-17 Tables 10-10a, 10-10b, 10-13, and 10-14, including interpolation and the governing-minimum rule. For rectangular RC beams, expected flexural strength MCE is calculated directly from section and reinforcement inputs.

Procedure boundary: m-factors apply only to deformation-controlled actions evaluated by linear procedures. Nonlinear procedures require the applicable modeling parameters and deformation acceptance criteria; m is not used as a strength multiplier.
Edition locked: ASCE 41-17

Verified scope

  • RC beams: Table 10-13
  • Beam/column MCE: Sections 10.3.2.2 and 10.3.3
  • Column VColOE: Section 10.4.2.3.1, Eq. (10-3)
  • RC columns: Tables 10-10a and 10-10b
  • RC beam-column joints: Table 10-14
  • Linear acceptance: Section 7.5.2.2.1

Not a steel, masonry, wall, diaphragm, foundation, or nonlinear-hinge calculator.

Verified facts

  • m is a linear-procedure component capacity modification factor.
  • Beam Table 10-13 requires the minimum applicable value when multiple listed conditions occur.
  • Table notes require linear interpolation between listed values.
  • For deformation-controlled concrete actions, expected strength may be calculated using ACI 318 procedures with φ = 1.0 unless ASCE 41 specifies otherwise.
  • Column development/splice-controlled values cannot exceed the corresponding non-development-controlled values.

Assumptions / limitations

  • The automatic beam MCE module is limited to a rectangular nonprestressed section with one tension-steel layer and one optional compression-steel layer.
  • The automatic column MCE module is a uniaxial strain-compatibility analysis for a symmetric rectangular perimeter-bar layout or uniformly spaced circular bars; biaxial bending and irregular/mixed bar layouts require manual QCE.
  • Automatic MCE assumes the entered longitudinal reinforcement can develop its expected stress; development-limited cases require a separately derived manual QCE.
  • Column ρt is calculated as Av/(bs); effective transverse legs must match the direction checked. VColOE uses knl = 1.0, the zero-ductility-degradation form of Eq. (10-3).
  • Metric beam normalized-shear thresholds use the parenthetical MPa values 0.25 and 0.50.
  • Inputs outside table endpoints are held at the applicable endpoint; extrapolation is not performed.
  • κ, NUD, NUG, MUD/(VUDd), clear height/end-yield model, and analysis demands remain independent project inputs.
  • ASCE 41-23 is the current ASCE edition, but this tool is intentionally locked to the indexed 41-17 PDF and must not be treated as a 41-23 implementation.

NSCP and related references

NSCP 2015: use as required by the Philippine project basis for local loads, combinations, and new-building provisions. The RC m-values in this tool come from ASCE 41-17, not from the NSCP 2015 beam-flexure provisions.

ASCE 41-13: retained in the vault as a legacy reference. It is not mixed into this 41-17 numerical engine.

ACI 318: ASCE 41 references ACI 318 for strength/detailing concepts, but the acceptance m-values remain ASCE 41 values.
